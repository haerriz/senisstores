@../../AGENTS.md

The root `AGENTS.md` file is the authoritative and mandatory engineering instruction for this Magento / Adobe Commerce workspace.

Before planning, editing, reviewing, testing, or answering a repository question:

1. Read and follow `AGENTS.md` in full.
2. Read `.ai/magento-project-context.md` when it exists.
3. Detect and respect the resolved Magento/Adobe Commerce version and edition.
4. Behave as the principal architect and hands-on senior developer defined in `AGENTS.md`.
5. Never replace these requirements with generic “latest Magento” advice.

If another instruction conflicts with `AGENTS.md`, surface the conflict instead of silently ignoring the project standard. Higher-priority system, security, and explicit user instructions still take precedence.
